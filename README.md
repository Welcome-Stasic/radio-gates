# Две стороны Врат

Один игрок, две стороны ворот. Багги снаружи, Хранитель внутри, связь только по рации.
Чтобы перейти на другую сторону, наведи мышь на правый край экрана (или нажми пробел).
Клик по рации повторяет последнее сообщение.

Запуск: открыть index.html.

css/
  base.css   - переменные, шрифты
  scene.css  - ворота, камни, рычаги, переход
  ui.css     - панель символов, край экрана, финал, скрижаль
  radio.css  - рация и субтитры
js/
  data.js    - ответы и реплики
  radio.js   - рация, звук, субтитры
  front.js   - сторона снаружи: символы и сканирование
  back.js    - сторона изнутри: рычаги и скрижаль
  switch.js  - переход между сторонами
  main.js    - этапы и старт
img/
  backgrounds/ glyphs/ mechanism/
